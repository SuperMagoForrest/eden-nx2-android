# Eden SX2A — Project Brain

Memoria persistente del fork di sviluppo **SuperMagoForrest/eden-nx2-android** (branch `sx2a/dev`).

## Come usare questo brain

1. Leggere `CURRENT_STATE.md` e `CHECKPOINT.md` all'inizio di ogni sessione.
2. Consultare `NEXT_ACTIONS.md` per il lavoro immediatamente eseguibile.
3. Aggiornare solo i documenti toccati dalle modifiche; non riscrivere tutto.
4. Ogni affermazione tecnica rilevante deve citare file, simbolo, commit, log o test.
5. Distinguere sempre lo stato evidenza: `VERIFIED` | `PARTIALLY_VERIFIED` | `IMPLEMENTED_NOT_TESTED` | `HYPOTHESIS` | `BLOCKED` | `NOT_STARTED`.
